## 일반 지식

### 가상 센서는 값을 어떻게 얻나?

- 조각: FDC_SENSOR
- 채점표: 다른 센서 값으로 수식을 계산해 얻는다

### ARG_ORDER 가 크면 중요한 입력 센서인가?

- 조각: FDC_SENSOR
- 채점표: ARG_ORDER 는 수식 인자 순서일 뿐 중요도가 아니다

### 센서 값의 단위 환산 규칙은?

- 조각: 없음

## 데이터 설명

### S-0004 는 물리 센서인가 가상 센서인가?

- 조회: sensor_row
- 입력: snsr_id=S-0004

### S-0004 값은 어느 메시지로 들어오나?

- 조회: sensor_row, message_row
- 입력: snsr_id=S-0004

## 데이터 연관

### S-0007 은 어떤 센서들로 계산되나?

- 조회: sensor_row, formula_row, formula_input_rows
- 채점표: 수식과 입력 센서를 인자 순서대로 함께 말한다
- 입력: snsr_id=S-0007
